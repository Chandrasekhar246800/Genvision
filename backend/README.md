# GenVision FastAPI backend

This service runs genuine CPU PyTorch inference with the verified
`models/unet_controlled_best.pth` U-Net checkpoint. It is isolated from the
Next.js frontend and does not modify existing model, dataset, or evaluation
artifacts.

## Installation

From the project root, activate the existing Python environment and install the
backend requirements:

```powershell
.\venv\Scripts\Activate.ps1
python -m pip install -r backend\requirements.txt
```

The existing environment must contain compatible PyTorch and torchvision
packages. The service defaults to CPU inference.

## Start the server

Run from the project root:

```powershell
python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000
```

The model is loaded once during application startup. The configured checkpoint
is `models/unet_controlled_best.pth`.

## Endpoints

### `GET /health`

Returns model lifecycle status:

```json
{
  "status": "ok",
  "model_loaded": true,
  "model_name": "U-Net"
}
```

### `GET /models`

Returns the verified model metadata, checkpoint size, and loaded state.

### `POST /predict`

Send a PNG or JPEG using the `file` multipart field:

```powershell
curl.exe -X POST http://127.0.0.1:8000/predict `
  -F "file=@dataset\cloudy\0.png" `
  --output results\api_test\reconstruction.png
```

The response body is a PNG generated by the PyTorch checkpoint. Response
headers include:

- `X-GenVision-Model`
- `X-Inference-Time-Ms`
- `X-Output-Type: genuine-pytorch-inference`

The service accepts files up to 12 MB and validates both the declared media
type and image decoding. Inputs are converted to RGB, resized to 256 x 256,
and converted with the same `Resize` plus `ToTensor` preprocessing used during
training. Outputs are clamped to `[0, 1]` and encoded as PNG.

## Current limitations

- The service supports only the selected U-Net checkpoint.
- Inputs are RGB; multispectral analysis is not implemented.
- CPU inference can take several seconds per image.
- No authentication, persistent storage, job queue, or batching is included.
- CORS is limited to local Next.js development origins
  (`localhost:3000` and `127.0.0.1:3000`).
- This endpoint returns a reconstructed image only; it does not calculate
  evaluation metrics.
